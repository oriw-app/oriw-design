# StatusPill

Compact rounded labels that show a board or connection state at a glance.

- **Success** (`o-pill o-pill--success`): Encrypted, Saved, Connected, Verified.
- **Accent** (`o-pill--accent`): live activity such as "Agent is editing" or "Live · 4".
- **Neutral** (`o-pill--neutral`): passive facts such as "Backed up 2m ago".

Always pair the colour with words; add an `o-dot` or a 13px icon before the text. Keep labels to three words or fewer. Never use a pill for normal states in `warning` or `danger`.
