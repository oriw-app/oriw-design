# oriw-design

The Oriw design system: colour, type, spacing, radius, shadow and layering tokens for light and dark themes, component styles, and the brand book.

| File | What |
| --- | --- |
| `tokens.json` | All design tokens, light and dark |
| `BRAND.md` | Brand book: principles, voice, colour, type, motion, accessibility |
| `components/bundle.css` | Component styles (buttons, tool dock, pills, stickies, agent steps) |
| `components/<Name>/` | Usage guidelines and a live preview for each component |

Fonts: Inter and JetBrains Mono, from Google Fonts.
